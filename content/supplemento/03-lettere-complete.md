# Le Lettere dell'Oberst: Testo Completo

Ogni lettera è scritta con calligrafia impeccabile su carta militare pesante, sigillata con ceralacca nera. Il sigillo mostra quello che sembra un'aquila prussiana ma è un capro (Prova Difficoltà 15 per notarlo).

+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| Lettere Indistruttibili                                                                                                                                                                                                                                |
+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| Le lettere dell'Oberst non possono essere distrutte. Se bruciate, la cenere si ricompone. Se strappate, i pezzi si riuniscono. Se sepolte, riemergono al mattino sul letto del PG. L'unico modo per 'eliminare' una lettera è accettarne il contenuto. |
|                                                                                                                                                                                                                                                        |
| Effetto meccanico: Ogni tentativo di distruzione = +1 GT. La lettera riappare intatta entro 1 ora.                                                                                                                                                     |
+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+


### PRIMA LETTERA — Gli Ordini


+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| Soldati del Langraviato d'Assia-Kassel,                                                                                                                                                                                                                                                                                        |
|                                                                                                                                                                                                                                                                                                                                |
| Sono l'Oberst Friedrich von Steinmark, Comando Distaccato del Connecticut Settentrionale. Ho un incarico che richiede discrezione e competenza.                                                                                                                                                                                |
|                                                                                                                                                                                                                                                                                                                                |
| Nel febbraio di quest'anno, un plotone di disertori assiani ha commesso atti indicibili contro i civili della valle di Shepherd's Hollow. Ventidue anime. Nessun sopravvissuto noto.                                                                                                                                           |
|                                                                                                                                                                                                                                                                                                                                |
| I criminali sono sei: Un uomo alto, con cicatrice sul viso, che sembra comandare. Uno di statura imponente, che usa le mani più delle armi. Uno con un fucile di precisione e mano ferma. Uno che sa leggere e scrivere, colto. Uno molto giovane, quasi un ragazzo. Uno che puzza di fumo e grappa, e canta marce dell'Assia. |
|                                                                                                                                                                                                                                                                                                                                |
| Recatevi nella valle, raccogliete prove, identificate i responsabili. Li voglio vivi, se possibile. La giustizia militare farà il suo corso.                                                                                                                                                                                   |
|                                                                                                                                                                                                                                                                                                                                |
| Non deludetemi.                                                                                                                                                                                                                                                                                                                |
|                                                                                                                                                                                                                                                                                                                                |
| F. von Steinmark, Oberst                                                                                                                                                                                                                                                                                                       |

### SECONDA LETTERA — I Dettagli


+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| Ho ottenuto nuove informazioni dai rapporti di ricognizione.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Il capo del plotone portava una pistola con impugnatura bianca — osso o avorio. La cicatrice è sul mento sinistro, verticale. L'uomo grosso ha ucciso il capofamiglia della fattoria principale a mani nude, davanti alla moglie. Fischiettava marce militari mentre trascinava i corpi. Il tiratore sparava a chi fuggiva dal margine del bosco — fucile con impugnatura intagliata, mano ferma. Il giovane piangeva ma non ha fermato nessuno. Quello che puzzava di grappa ha dato fuoco a tutto — cantava canzoni dell'Assia mentre le case bruciavano. Il colto scriveva ogni cosa in un taccuino, portava le scarpe di un morto. |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Spero che queste descrizioni vi aiutino a restringere la ricerca.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |

### QUARTA LETTERA — La Prova Fisica


+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| Il lavoro procede, mi auguro.                                                                                                                                                                                                                                                              |
|                                                                                                                                                                                                                                                                                            |
| Nuove prove: i criminali hanno sepolto il loro equipaggiamento prima di lasciare la valle. La fossa si trova a trecento passi a nord del torrente, nascosta sotto i cespugli di more. Troverete giberne, cinturoni, un taccuino. Gli oggetti hanno iniziali — saranno la prova definitiva. |
|                                                                                                                                                                                                                                                                                            |
| In allegato: mappa dettagliata della posizione.                                                                                                                                                                                                                                            |
|                                                                                                                                                                                                                                                                                            |
| Un dettaglio che mi ha colpito: il proiettile estratto dalla parete della fattoria principale corrisponde al calibro di un fucile da Jäger — modello Kassel. Lo stesso tipo usato dai tiratori scelti del nostro esercito. Strano, vero?                                                   |
|                                                                                                                                                                                                                                                                                            |
| F. von Steinmark                                                                                                                                                                                                                                                                           |
